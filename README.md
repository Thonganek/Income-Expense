# MoneyBook Standalone / GAS

โปรแกรมบัญชีรายรับรายจ่ายที่รองรับ 2 แบบในชุดไฟล์เดียว

- เปิด `Index.html` ในคอมโดยตรง: ใช้โหมด Standalone และบันทึกข้อมูลใน Browser เครื่องนั้น
- เปิดผ่าน Google Apps Script Web App: ใช้โหมด GAS และบันทึกข้อมูลลง Google Sheet

ทั้งสองโหมดใช้หน้าโปรแกรมเดียวกัน และเข้าสู่ระบบด้วย `admin / admin1234` ในครั้งแรก

## โครงหน้าจอ

มี 2 หน้าหลัก สลับได้จากแถบบน (มือถือจะเป็นแถบล่าง)

- **หน้าแรก** – Dashboard ทั้งหมดในหน้าเดียว: การ์ดรายรับ / รายจ่าย / สรุปสุทธิ / ยอดคงเหลือ, กราฟแท่งรายรับ-รายจ่ายรายวัน, ปฏิทินที่แสดงยอดรับ-จ่ายของแต่ละวัน (แตะวันเพื่อดู/เพิ่มรายการ), กราฟแท่งย้อนหลัง 6 เดือน, สรุปเดือน, รายจ่ายตามหมวด, งบประมาณ, ยืม-ให้ยืม และบัญชี
- **รายละเอียด** – แท็บครบทุกงาน: ธุรกรรม (ค้นหา/กรอง/แก้ไข/ลบ), รายงาน (กราฟ + ตาราง + CSV + พิมพ์), สรุปรายเดือน (กราฟแท่งรายรับ-รายจ่าย + เส้นยอดสุทธิ 12 เดือน และตารางรายเดือนพร้อมยอดสะสม), งบประมาณ, บัญชี, หมวดหมู่ (เพิ่ม/แก้ไข/ลบผ่านฟอร์ม), ยืม-ให้ยืม (ติดตามค้างคืน/เลยกำหนด), ข้อมูล (สำรอง/นำเข้า/ล้าง/ข้อมูลตัวอย่าง)

ปุ่ม **＋ เพิ่มรายการ** อยู่ที่แถบบนทุกหน้า และหน้าเก่าก่อนปรับ Layout เก็บไว้ที่ `_backup/Index.before-redesign.html`

## ฟีเจอร์เสริม

- **หมวดหมู่สำเร็จรูป** – แท็บหมวดหมู่มีชุดหมวดรายจ่าย 27 แบบ / รายรับ 14 แบบ พร้อมอีโมจิและสี กดเพิ่มทีละหมวดหรือ "เพิ่มทั้งชุด" แล้วแก้ไขทีหลังได้ ฟอร์มเพิ่มหมวดมีแถบอีโมจิให้เลือกไอคอน
- **เงินเก็บ** – บัญชีเลือกประเภทได้ว่า "ใช้จ่าย" หรือ "เงินเก็บ" และตั้งเป้าหมายได้ หน้าแรกแยกแสดงยอดเงินเก็บ ความคืบหน้าตามเป้า และปุ่ม "＋ เก็บเงิน" (โอนจากบัญชีใช้จ่ายเข้าบัญชีเงินเก็บ)
- **ข้อมูลตัวอย่าง** – แท็บข้อมูล › "ใส่ข้อมูลตัวอย่างย้อนหลัง 1 เดือน" สร้างบัญชี 3 บัญชี (ยอดตั้งต้นรวม 1,000,000 บาท) หมวดหมู่ งบ และธุรกรรมประมาณ 120 รายการ ใช้ได้ทั้งสองโหมด ในโหมด GAS จะรัน `seedDemoData()` จาก Apps Script ก็ได้ (ข้อมูลเดิมของผู้ใช้นั้นจะถูกแทนที่)
- **ดีไซน์** – ธีม hologram โทนสว่าง (การ์ดกระจกโปร่ง ขอบสีรุ้ง) ใช้สีรายรับเขียว / รายจ่ายแดง / ยืมน้ำเงิน / ให้ยืมม่วง ตลอดทั้งแอป

## ชีตในโหมด GAS

ชีต `MM_Wallets` มีคอลัมน์เพิ่ม `Kind` (spending/savings) และ `Goal` ต่อท้าย ระบบจะเติมหัวคอลัมน์ให้เองตอนเข้าสู่ระบบ ไม่ต้องรัน `setupSheet()` ซ้ำ (การรันซ้ำจะล้างข้อมูลทั้งหมด)

## สต็อกซื้อ-ขายข้าว

ข้อมูลซื้อ-ขายข้าวอยู่ในชีต `MM_Rice` และแยกจากบัญชีรายรับรายจ่าย ไม่สร้างธุรกรรมใน `MM_Transactions`

- รับซื้อข้าว: เก็บชนิดข้าว น้ำหนักรวม และราคาซื้อบาท/กก.
- ขายข้าว: เก็บชื่อผู้ซื้อ น้ำหนักรวม ราคาขายบาท/กก. ราคาสุทธิ สถานะจ่ายแล้ว/ยังไม่จ่าย และวันที่จ่าย
- หน้าสต็อกข้าวคงเหลือรวมข้าวชนิดเดียวกัน แล้วหักยอดขาย/ตักออก/รวมออก เพื่อแสดงคงเหลือเป็นกิโลกรัม

## ใช้แบบ Standalone

1. เปิดไฟล์ `Index.html` ได้ทันที
2. เข้าสู่ระบบด้วย:
   - Username: `admin`
   - Password: `admin1234`
3. ข้อมูลจะเก็บใน Browser ของเครื่องนั้นผ่าน `localStorage`

## ใช้แบบ GAS + Google Sheet

1. สร้าง Google Sheet ใหม่
2. ไปที่ Extensions > Apps Script
3. สร้าง/วางไฟล์ `code.gs` และ `Index.html`
4. ถ้าต้องการใส่ manifest ให้เปิด Project Settings > Show appsscript.json แล้ววาง `appsscript.json`
5. กด Run > `setupSheet()` หนึ่งครั้ง เพื่อสร้างชีตและคอลัมน์
6. Deploy > New deployment > Web app
7. เปิด Web App URL แล้วเข้าสู่ระบบด้วย `admin / admin1234`

ในโหมด GAS รหัสผ่านอยู่ในชีต `MM_Users` คอลัมน์ `Password` สามารถแก้ไขใน Google Sheet ได้โดยตรง

## ย้ายข้อมูลจาก GitHub Pages ไป Google Sheet

ข้อมูลที่เปิดผ่าน GitHub Pages จะอยู่ใน Browser เครื่องนั้น ให้ย้ายด้วยไฟล์สำรอง:

1. เปิดหน้า GitHub Pages ในเครื่อง/Browser ที่มีข้อมูลเดิม
2. ไปที่ รายละเอียด > ข้อมูล > `ส่งออกไฟล์สำรอง (JSON)`
3. เปิด Web App URL ที่ Deploy จาก Apps Script และเข้าสู่ระบบผู้บริหาร
4. ไปที่ รายละเอียด > ข้อมูล > `นำเข้าไฟล์สำรอง`
5. เลือกไฟล์ JSON ที่ส่งออกมา ระบบจะเขียนข้อมูลลง Google Sheet

ไฟล์สำรองเวอร์ชันใหม่รวมทั้งสมุดบัญชีและข้อมูลซื้อ-ขายข้าว (`MM_Rice`) แล้ว

## GitHub Pages ดึงข้อมูลจาก Google Sheet เท่านั้น

Web App URL ฝังไว้ใน `Index.html` (ค่าคงที่ `GS_WEBAPP_URL`) เมื่อเปิดหน้า GitHub Pages ระบบจะดึงข้อมูลจาก `.../exec?action=getBackup` มาแสดงใน Dashboard และทุกการบันทึกจะส่งกลับเข้า Google Sheet ส่วน localStorage ใช้เป็นแคชชั่วคราวเท่านั้น

- ถ้าโหลดจาก Google Sheet ไม่ได้ จะยังเข้าใช้งานไม่ได้ ไม่แสดงข้อมูลเก่าในเครื่อง
- ถ้า Google Sheet ยังว่างแต่ Browser มีข้อมูลเดิม ระบบจะส่งข้อมูลเดิมขึ้น Google Sheet ให้หนึ่งครั้ง
- ข้อมูลเดิมในเครื่องถูกสำรองไว้ก่อนถูกแทนที่ครั้งแรก กู้ได้จาก รายละเอียด › ข้อมูล › `กู้ข้อมูลเดิมในเครื่องนี้`

## บันทึกจาก GitHub Pages ลง Google Sheet โดยตรง

หน้า GitHub Pages มีปุ่ม `บันทึก GS` และกล่องตั้งค่าใน รายละเอียด > ข้อมูล > บันทึกลง Google Sheet

1. Deploy Apps Script เป็น Web app และคัดลอก Web App URL ที่ลงท้ายด้วย `/exec`
2. เปิดหน้า GitHub Pages
3. ไปที่ รายละเอียด > ข้อมูล > บันทึกลง Google Sheet
4. วาง Web App URL แล้วกด `บันทึกค่า`
5. กด `บันทึกลง Google Sheet ตอนนี้` หรือใช้ปุ่ม `บันทึก GS` บนแถบบน

หลังตั้งค่าแล้ว เมื่อกดปุ่มบันทึกในหน้าต่าง ๆ ระบบจะบันทึกใน Browser และส่งสำเนาข้อมูลไป Google Sheet อัตโนมัติ

ถ้าต้องการล็อกการรับข้อมูล ให้ตั้ง Script Property ชื่อ `MM_SYNC_KEY` ใน Apps Script แล้วใส่รหัสเดียวกันในช่อง `รหัส Sync`
